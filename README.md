# lightweight link shortener

built with [Nuxt](https://nuxt.com)

## work on it yourself

1. install dependencies

```bash
npm install
```

2. dev server

by default this opens it on port 3000

```bash
npm run dev
```

## production

build it:

```bash
npm run build
```

## .env file format

```env
# get these values from an app on https://discord.com/developers/applications
DISCORDCLIENTID = <number>
DISCORDCLIENTSECRET = <secret>
DISCORDCALLBACK = <callback>
DISCORDAUTHLINK = <authlink>
```
